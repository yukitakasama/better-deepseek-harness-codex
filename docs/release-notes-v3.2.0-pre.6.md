# v3.2.0-pre.6 发布说明 / Release Notes

## 中文

### 摘要

- 基座 DSH 版本：0.2.2-rc.5。
- 整合包版本：3.2.0-pre.6。
- 实际挂载插件：18 个。
- 移除 `dsh-pet`、`dsh-deep-ptc-mode`、`dsh-plugin-tool-management` 和 `dsh-research`；这些包不再进入依赖或 profile bundle。
- 本版本为预发布候选，发布为 GitHub pre-release，不标记为 stable/latest。

### 验证与发布状态

- CI 检查双语发布说明、插件兼容声明、启动器字段结构及 dspack 构建和归档元数据。
- 当前基座为 DSH 0.2.2-rc.5；剩余插件的运行时行为仍以目标环境实测为准。

## English

### Summary

- Base DSH version: 0.2.2-rc.5.
- Modpack version: 3.2.0-pre.6.
- Mounted plugins: 18.
- Removes `dsh-pet`, `dsh-deep-ptc-mode`, `dsh-plugin-tool-management`, and `dsh-research`; these packages are no longer dependencies or profile bundles.
- This is a prerelease candidate and will be published as a GitHub pre-release, not marked stable/latest.

### Validation and Release Status

- CI checks bilingual release notes, plugin compatibility declarations, launcher fields, dspack construction, and archive metadata.
- The base is DSH 0.2.2-rc.5; runtime behavior of the remaining plugins still depends on validation in the target environment.
