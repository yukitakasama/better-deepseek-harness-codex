# v3.2.0-pre.5 发布说明 / Release Notes

## 中文

### 摘要

- 基座 DSH 版本：0.2.2-rc.5。
- 整合包版本：3.2.0-pre.5。
- 实际挂载插件：22 个；插件集合与 v3.2.0-pre.4 相同。
- 修复导入兼容性：`manifest.launchers` 使用导入器要求的对象格式，明确声明 `dshl` 与 `dsh-packforge-app` 支持本整合包（#6）。
- 本版本为预发布候选，不标记为 stable/latest。

### 验证与发布状态

- CI 检查双语发布说明、插件兼容声明、启动器字段结构及 dspack 构建和归档元数据。
- 当前基座为 DSH 0.2.2-rc.5；工具管理面板要求 Node.js `>=24.9`。

## English

### Summary

- Base DSH version: 0.2.2-rc.5.
- Modpack version: 3.2.0-pre.5.
- Mounted plugins: 22; the plugin set is unchanged from v3.2.0-pre.4.
- Fixes import compatibility by using the object form required by the importer for `manifest.launchers`, explicitly declaring support for `dshl` and `dsh-packforge-app` (#6).
- This is a prerelease candidate and will not be marked stable/latest.

### Validation and Release Status

- CI checks bilingual release notes, plugin compatibility declarations, launcher field structure, dspack construction, and archive metadata.
- The base is DSH 0.2.2-rc.5; the tool management panel requires Node.js `>=24.9`.
