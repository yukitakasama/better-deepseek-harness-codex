# qq-chat-style-miner：从 QQ 聊天记录提炼用户风格

## 触发场景
用户说「分析我的 QQ 聊天风格 / 提炼我的说话习惯 / 从聊天记录生成 persona / 让 AI 学我说话」，
或直接提供 QQ 导出文件 / 粘贴一段对话时。

## 输入
- **QQ 聊天记录导出**：手机 QQ → 设置 → 通用 → 聊天记录备份与迁移 → 导出为 txt/json；
  或电脑 QQ 右键会话「导出消息记录」。
- 也可直接粘贴一段对话文本（标注发言者）。
- **理想样本**：≥ 200 条「用户」本人发言、跨多个会话、含日常闲聊，避免只有工作对话。

## 方法（四步）

1. **清洗与切分**
   - 按发言者拆分，区分「用户」与「对方」。识别时间戳、系统消息、撤回（`[撤回]`）、引用。
   - 剔除图片/语音占位行（保留 `[图片]` `[语音]` 标注即可，不影响风格判断）。

2. **维度打分**（每个维度给出「观察 + 原句例证」）
   - 语气与礼貌度：敬语 / 口语 / 粗口 / 撒娇 / 阴阳
   - 常用口语词与方言：如「嘛」「呗」「咋」「咱」「yyds」「绝绝子」「栓 Q」
   - 标点与表情：emoji 频率与种类、颜文字、叠词（「好好好好」）、句尾语气词（「哈」「呀」「捏」「捏」）
   - 句式：长句 / 短句、反问、省略主语、中英文混用、是否爱用「……」拖尾
   - 回复节奏：平均字数、是否爱发「+1」「收到」「在的」「好嘞」、是否常已读不回
   - 话题与兴趣：高频主题、梗、追的番 / 游戏 / 爱豆 / 博主
   - 情绪表达：直球 / 内敛、是否爱用夸张修辞、是否爱用反问表确认

3. **聚类成画像**
   把维度归纳为 **3–5 条「风格规则」**，每条给「当用户说 X 时，倾向这样回」的示范。

4. **产出档案**（两份）
   - `STYLE.md`：人读的风格画像 + 可直接粘进 system prompt 的「拟人化指引」段落。
   - `style.json`：结构化字段（`tone` / `dialect` / `emoji_habit` / `sentence_pattern` /
     `reply_rhythm` / `topics` / `example_replies[]` / `confidence`），供程序消费。

## 输出模板（STYLE.md）

```
# 用户风格档案：<昵称>

## 一句话画像
<用一句话概括>

## 风格规则（按权重）
1. <规则 + 原句例证>
2. ...

## 禁忌（不要这样模仿）
- ...

## 拟人化系统提示词（可直接用）
你是<昵称>，<基于上述规则生成的 persona 指引，用第二人称/现在时描述行为倾向>。

## 范例回复
- 正面范例：用户说「…」→ 你这样回：「…」
- 反例（避免）：「…」
```

## 注意事项
- **只提炼「用户」本人风格**，不要混入对方；若需对比，单独成节。
- 涉及隐私的聊天对象姓名 / 电话 / 地址 / 账号做脱敏（用 `<脱敏>` 占位）。
- 风格是概率性的，输出「倾向」而非「绝对」，并对整体结论给 `confidence`（高/中/低）。
- 若样本过少（< 50 条），明确告知结论置信度低，建议补充更多记录。
